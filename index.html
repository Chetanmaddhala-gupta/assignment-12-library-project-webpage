Explore the project ↓

WHAT IT CAN DO

Everyday library tasks, in one simple program.

01

Keep a catalogue

Add books with a title and author, then view the collection.

02

Borrow a book

Mark an available book as borrowed and prevent duplicate borrowing.

03

Return a book

Update its status so it can be borrowed again.

HOW IT WORKS

Small classes, clear responsibilities.

The Book class stores the title, author and borrowing status. The Library class manages the collection and provides actions to add, find, borrow and return books. A menu lets the user choose what to do.

library = Library()library.add_book(Book( "The Hobbit", "J. R. R. Tolkien"))library.borrow("The Hobbit")

WHAT I LEARNED

Practice that builds on the basics.

This project connects classes, lists, methods, loops and user input. A next step is saving the catalogue to a file so books are still there after the program closes.
